# 🚀 Quick Setup Guide

## Step 1: Install Dependencies

```bash
cd react-portfolio
npm install
```

## Step 2: Update Images (Optional)

The portfolio currently uses placeholder images from Unsplash. You can replace them later:
- Profile image in Hero section (currently using Unsplash placeholder)
- About section image (currently using Unsplash placeholder)
- Project images (currently using Unsplash placeholders)

To use your own images:
1. Place images in the `public` folder
2. Update image paths in component files (Hero.jsx, About.jsx, Projects.jsx)

## Step 3: Start Development Server with Vite

```bash
npm run dev
```

The app will automatically open at `http://localhost:3000`

**Vite Benefits:**
- ⚡ Lightning-fast HMR (Hot Module Replacement)
- 🚀 Instant server start
- 📦 Optimized production builds

## Step 4: Customize

1. Update personal information in component files
2. Replace images with your own
3. Update project details
4. Modify colors in CSS files if needed

## Step 5: Build for Production

```bash
npm run build
```

The optimized build will be in the `build` folder, ready to deploy!

---

**That's it! Your React portfolio is ready! 🎉**
